# STEM Genius for macOS

Free native macOS study app for STEM practice.

## Requirements

- macOS 26.0 or later

## Download

Use `STEM-Genius-macOS.app.zip`. Unzip it, then open `STEM Genius.app`.

## First Launch

This build is ad-hoc signed and not notarized. If macOS blocks the first launch,
Control-click the app, choose Open, then confirm once. A future Developer ID
release can remove that extra first-launch step.

## Contents

This repository intentionally contains only the public macOS app artifact,
release manifest, and public release notes. It does not contain the STEM Genius
source project.
